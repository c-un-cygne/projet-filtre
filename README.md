# projet-filtre
L’objectif de ce projet est de recréer, en Python, un jeu qui a été très populaire sur les réseaux sociaux, comme TikTok ou Instagram. Ce jeu consiste à faire s’affronter deux cercles dans une arène, chacun disposant d’un certain nombre de points de vie. Le premier dont les points de vie tombent à zéro est déclaré perdant. Ce jeu est intéressant dans la mesure où ce projet a pour but de permettre à toute personne de créer une nouvelle classe de personnage, avec des effets différents, afin d’essayer de battre ceux des autres.
